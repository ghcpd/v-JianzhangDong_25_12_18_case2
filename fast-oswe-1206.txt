## 📦 How to run CI / CD locally (PowerShell / Windows)
> Note: run the scripts from their directories so the relative paths in the `.bat` files resolve.

```powershell
# 1) Create a clean environment (delete any existing .venv)
if (Test-Path .venv) { Remove-Item -Recurse -Force .venv }
python -m venv .venv

# 2) Install dependencies into the venv
.venv\Scripts\python -m pip install -r requirements.txt

# 3) Run CI (from the ci/ directory)
Push-Location ci
$env:Path = (Resolve-Path '..\.venv\Scripts').Path + ';' + $env:Path
& .\ci_pipeline.bat
Pop-Location

# 4) Run CD (from the cd/ directory)
Push-Location cd
$env:Path = (Resolve-Path '..\.venv\Scripts').Path + ';' + $env:Path
& .\cd_pipeline.bat
Pop-Location
```
